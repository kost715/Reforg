# GZW NightVision Test

Тестовый мод ночного видения для **Arma Reforger**, созданный для экспериментов с постобработкой камеры в **Reforger Workbench**.

Проект добавляет зелёный HDR-эффект, зерно изображения и круглую маску в стиле PVS-14. Это самостоятельный прототип для проверки визуальных настроек, а не готовая система ПНВ со шлемами, креплениями и инвентарём.

> **Статус:** ранний прототип. Используйте отдельную тестовую сцену; перед применением в других модах требуется доработка и проверка в игре.

## Возможности

- Включение и выключение ночного видения клавишей.
- Регулировка усиления изображения.
- Настраиваемые HDR и FilmGrain-материалы.
- Маска однотрубного прибора ночного видения.
- Готовая тестовая сцена на основе стандартного мира Conflict — Everon.
- Без сторонних модов и дополнительных зависимостей, кроме базовой игры.

## Управление

| Действие | Клавиши |
| --- | --- |
| Включить или выключить ПНВ | `N` |
| Увеличить усиление | `Left Shift` + `=` |
| Уменьшить усиление | `Left Shift` + `-` |

Действия доступны в контексте управления персонажем `CharacterGeneralContext`.

## Запуск в Workbench

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/kost715/Reforg.git
   ```

2. Откройте проект `addon.gproj` через Arma Reforger Workbench.
3. Дождитесь регистрации ресурсов проекта. Если Workbench создаёт недостающие `.meta`-файлы, сохраните их вместе с проектом.
4. Откройте тестовый мир `Worlds/GZW_Test.ent` или сценарий `GZW Night Vision - Test`.
5. Запустите сцену в режиме игры и используйте клавиши из таблицы выше.

## Как это работает

На тестовой сцене находится сущность с компонентом `GZW_NightVisionTestComponent`. Компонент регистрирует действия ввода и применяет к текущей камере два постпроцесса:

- `Assets/NVG/GZW_PVS14_HDR.emat` — экспозиция, цвет, контраст и маска ПНВ;
- `Assets/NVG/GZW_PVS14_Grain.emat` — монохромное зерно изображения.

Пути к материалам и шаг усиления можно изменить в свойствах компонента через Workbench.

## Структура проекта

```text
Assets/NVG/                         HDR, FilmGrain и маска ПНВ
Configs/System/chimeraInputCommon.conf
                                    Действия и сочетания клавиш
Missions/                           Описание тестового сценария
Worlds/                             Тестовый мир и его слои
scripts/Game/                       Компонент управления эффектом
addon.gproj                         Проект Reforger Workbench
```

## Текущие ограничения

- Нет проверки шлема или другого оборудования: эффект переключается напрямую клавишей.
- Проект предназначен прежде всего для локального тестирования на PC.
- Переключение камер при активном эффекте и восстановление прежних настроек камеры требуют доработки.
- Регулировка экспозиции нуждается в ограничении допустимых значений.
- Multiplayer и консольные платформы не проверялись.
